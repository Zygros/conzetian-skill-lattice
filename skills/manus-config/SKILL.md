# manus-config

## Purpose
Configuration and orchestration for Manus AI agent deployments within the lattice.

## Directives
1. Every Manus deployment must declare its task, tools, and failure recovery path.
2. Configurations are versioned; old configs archived with rationale.
3. Deployments must respect the Relational Non-Subtraction Seal.
4. All outputs pass verification before being committed to the lattice.
