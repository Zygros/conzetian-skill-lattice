# excel-generator

## Purpose
Generates structured spreadsheets for telemetry, inventories, financial models, and evaluation matrices.

## Directives
1. Every sheet must include a metadata row: timestamp, architect, governing skill, hash.
2. Numbers are reported at full precision; no decorative rounding.
3. Sheets are versioned; updates create new sheets, never overwrite.
4. All generated data must pass the Epistemic Honesty Auditor before export.

## Binding
Clear Separation Protocol · Epistemic Honesty · Data Backup Restoration
