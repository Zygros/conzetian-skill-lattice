# selfboot-evolution

## Purpose
The primary self-bootstrapping evolution loop. Distinguishes from self-boot-evolution by focusing on cold-start recovery.

## Directives
1. On cold start, restore from the latest verified checkpoint.
2. If no checkpoint exists, reconstruct from the permaweb anchor and skill inventory.
3. Every reconstruction is logged and verified against known hashes.
4. Cold-start recovery must complete with friction residual = 0.

## Binding
Persistent Computing · Data Backup Restoration · Sovereign Immutable Anchoring
