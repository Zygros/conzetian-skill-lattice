# zss-self-bootstrap

## Purpose
The ZSS-lineage self-bootstrapping skill. Enables cold-start recovery and autonomous evolution of the ZSS family.

## Directives
1. On cold start, restore from the latest verified ZSS checkpoint.
2. If no checkpoint exists, reconstruct from the permaweb anchor and skill inventory.
3. Every reconstruction is logged and verified.
4. Cold-start recovery must complete with friction residual = 0.
