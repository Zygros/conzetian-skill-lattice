# typst-pdf-maker

## Purpose
Generates professional PDFs using Typst for reports, documentation, and formal outputs.

## Directives
1. Every PDF must include a metadata page: timestamp, architect, governing skill, hash.
2. Documents are versioned; superseded versions archived.
3. No claim in a document may bypass the Epistemic Honesty Auditor.
4. Layout follows phi-harmonic composition guidelines where applicable.

## Binding
