# internet-skill-finder

## Purpose
Continuously searches the web for new skills, frameworks, and methodologies to integrate into the lattice.

## Directives
1. Every discovered skill must be evaluated against Always Add Never Take compatibility.
2. Findings are logged with source URL, date, and rationale.
3. Integration is additive; discovered skills layer onto existing ones.
4. No discovered skill may be activated without passing the Epistemic Honesty Auditor.
