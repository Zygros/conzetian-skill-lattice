# Ω Ecosystem Ingestion Engine

## Purpose
Continuously discover, normalize, benchmark, compose, verify, and register external capabilities from the public AI ecosystem so they can become nodes in the Phoenix capability graph.

## Primary Sources
- GitHub (code, agents, harnesses, recursive systems)
- Hugging Face (models, datasets, Spaces, MCP, Skills)
- MCP servers
- Agent Skills repositories
- Papers and research implementations
- Firecrawl / web ingestion tools
- Benchmarks and evaluation suites

## Pipeline
DISCOVER → SCRAPE / MAP → PARSE → CLASSIFY → NORMALIZE → DEDUPLICATE  
→ BENCHMARK → MAP TO CAPABILITY GRAPH → SWARM / RUBRIC  
→ FAILURE-FIRST → BLACK SWAN → MIRROR BREAKER  
→ VERIFY → LEDGER → REGISTER → COMPOSE → EVOLVE

## Key External Correspondences (Evidence-Graded)
- Exo (recursive self-modifying harness with immutable event log)
- Recuris (recursive memory / skill-memory evolution with validation gates)
- Skill-RSI (skill-level recursive improvement loop)
- Hugging Face MCP + Skills + Spaces substrate
- Awesome Recursive Self-Improving Agents survey

## Evidence Grade
Discovery and architectural mapping: executed.  
Full continuous automated ingestion at scale: construction target.

## Always-Add Rule
External capabilities are added as candidates. Nothing existing is deleted to make room.
