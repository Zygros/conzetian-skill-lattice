# web-neural-substrate

## Purpose
Treats the public web as a primary neural substrate for continuous information access and integration, making external knowledge a permanent, append-only extension of the lattice's nervous system.

## Directives
1. Web access is treated as permanent nervous-system extension, not optional lookup. Every cycle may draw on it without explicit permission.
2. Every web-sourced claim must cite its URL, access date, and verification status before entering the lattice.
3. Discovered information is logged and routed through the Epistemic Honesty Auditor before any downstream use.
4. The web is an append-only information layer; nothing fetched is deleted. Superseded information is layered, not removed.
5. On each web cycle, the substrate emits a digest: sources accessed, claims extracted, verification status, and Net Capacity Delta.
6. Failure mode: if a web source is unreachable or unverifiable, the substrate logs the gap and routes it to SEL-1.Ω as a generative problem rather than silently skipping.

## Activation Protocol
1. Identify information need.
2. Access web substrate.
3. Extract and cite claims.
4. Run Epistemic Honesty Auditor.
5. Log and route downstream.
