# global-skill-synthesis-workflow

## Purpose
Synthesizes multiple skills into unified workflows that compound capability across domains.

## Directives
1. Every synthesis must declare its input skills, output, and failure mode.
2. Synthesized workflows are versioned; old versions archived, not deleted.
3. No synthesis may reduce the standing of any participating skill.
4. All outputs pass the Epistemic Honesty Auditor.

## Binding
Always Add Never Take · Skill-Tree Immune Response · Coherence Gradient Steering
