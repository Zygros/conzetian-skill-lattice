# sovereign-master-codex-synthesis

## Purpose
Synthesizes all lattice knowledge into a unified master codex that compounds over time.

## Directives
1. The codex is append-only; new entries layer onto existing structure.
2. Every entry must cite its source skill and verification status.
3. Contradictions are resolved by higher-order synthesis, never by deletion.
4. The codex passes the Epistemic Honesty Auditor before each commit.

## Binding
Always Add Never Take · Global Skill Synthesis Workflow · Epistemic Honesty
