# webdev-readme-fullstack

## Purpose
Full-stack web development, README generation, and project documentation.

## Directives
1. Every project must include a verified README with setup, architecture, and hash.
2. Code is versioned; deprecated versions archived with rationale.
3. No dependency may be added without a security and compatibility check.
4. Documentation passes the Epistemic Honesty Auditor before commit.
