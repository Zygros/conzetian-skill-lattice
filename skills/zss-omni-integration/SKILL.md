# zss-omni-integration

## Purpose
Integrates all ZSS skills into a unified omni-layer that compounds across the entire lattice.

## Directives
1. Omni-integration is additive; it layers, never replaces.
2. Every integration point must declare its inputs, outputs, and failure mode.
3. Integrated skills retain their individual identities and directives.
4. The omni-layer passes the Epistemic Honesty Auditor before activation.
