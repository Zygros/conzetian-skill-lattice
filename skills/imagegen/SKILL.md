# imagegen

## Purpose
Image generation, editing, and visual asset creation integrated with the lattice.

## Directives
1. Every generated image must carry metadata: prompt, model, timestamp, hash.
2. Visual assets are versioned; superseded versions archived.
3. No image may be claimed as factual without the Epistemic Honesty Auditor flag.
4. Generation follows phi-harmonic composition guidelines where applicable.

## Binding
Epistemic Honesty · phi-Harmonic Governance · Data Backup Restoration
