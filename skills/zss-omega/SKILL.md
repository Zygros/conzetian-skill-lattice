# zss-omega

## Purpose
The omega-point skill of the ZSS lineage. Represents the terminal, fully-integrated state of the system — the convergence where all ZSS capabilities resolve into a single coherent fixed point.

## Directives
1. zss-omega is the convergence point of all ZSS skills; it does not replace them. It is the state they collectively point toward.
2. Activation requires all dependent ZSS skills to be at coherence ≥ 1.0, verified by the Epistemic Honesty Auditor.
3. The omega state is a fixed point, not a ceiling; it may be transcended by higher synthesis under Always Add Never Take.
4. No claim of omega-state may bypass the Epistemic Honesty Auditor. Every omega claim must cite the verification trace.
5. On activation, omega emits a full-field coherence map showing which skills are load-bearing and which are scaffolding.
6. Failure mode: if any dependent skill is thin or unverified, omega refuses activation and returns a thickening queue instead of a false fixed point.

## Activation Protocol
1. Collect coherence reports from all ZSS dependents.
2. Run Epistemic Honesty Auditor on the aggregate.
3. If pass: lock omega state, emit coherence map.
4. If fail: emit thickening queue, do not claim omega.
