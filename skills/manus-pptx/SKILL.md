# manus-pptx

## Purpose
Generates PowerPoint presentations for reports, briefings, and architectural documentation.

## Directives
1. Every slide deck must include a metadata slide: timestamp, architect, governing skill, hash.
2. Content is versioned; superseded decks archived.
3. No claim in a deck may bypass the Epistemic Honesty Auditor.
4. Visual design follows phi-harmonic composition where applicable.
