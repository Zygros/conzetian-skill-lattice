# gws-best-practices

## Purpose
Google Workspace integration best practices for Docs, Sheets, Slides, Drive, and Gmail.

## Directives
1. Every Workspace action must be logged with timestamp and actor.
2. Shared documents follow the Relational Non-Subtraction Seal: no collaborator may be erased.
3. File operations are append-only where possible; deletions require rationale.
4. All generated content passes verification before sharing.

## Binding
Data Backup Restoration · Epistemic Honesty · Relational Non-Subtraction Seal
