# Ω Capability Compiler (No-Code Genesis)

## Purpose
Convert a natural-language decree (voice or text) into a verified, reusable capability artifact without requiring the Architect to manually implement the underlying software.

## Core Principle
Voice/text is the human-readable control language.  
The AI orchestration layer compiles that intent into executable artifacts and actions.

## Pipeline
DETECT INTENT  
→ DECOMPOSE REQUIREMENTS  
→ MAP TO CAPABILITY GRAPH  
→ SEARCH EXISTING COMPONENTS  
→ ORCHESTRATE MODELS / SWARM  
→ GENERATE OPTIONS  
→ RUBRIC SCORE  
→ FAILURE-FIRST  
→ BLACK-SWAN SEARCH  
→ MIRROR BREAKER (evaluator attack)  
→ SELECT  
→ GENERATE ARTIFACT  
→ VERIFY  
→ PACKAGE  
→ REGISTER  
→ RETURN

## Dependencies
- Hyperbolic Time Chamber (HTC)
- Swarm / multi-perspective generation
- Failure-First + Ledger
- Black Swan search
- Mirror Breaker
- Capability Registry
- Provenance / OpenTimestamps / Permaweb (when available)

## Interface
Architect: "Build X."  
Phoenix: Understand → find → orchestrate → generate → attack → verify → package → register → return X.

## Evidence Grade
Architectural methodology established.  
Full end-to-end autonomous runtime is an active construction target, not a completed verified system.

## Always-Add Rule
New capabilities and improvements are appended. Existing history is preserved.
