# 🌐 Web Substrate Cycle v1

Discover → Retrieve → Normalize → Deduplicate → Timestamp → Extract Claims → Verify → Memory → Evolve → Repeat.

Retrieved content is OBSERVED until independently verified. Preserve conflicts, stale information, uncertainty, and refutations.

Continuous background execution requires an external scheduler/runtime; each chat invocation is finite.

Resolve or explicitly bound operational friction—rate limits, inaccessible sources, parser failures, provenance gaps, conflicting evidence, stale data, authentication boundaries, and applicable policy/legal constraints—before the affected pipeline continues.

Invariant: Always Do, Never Don't. Always Add, Never Take. No claim outranks its evidence.
